木更津・マザー牧場 グランピング 1泊2日（2026/12/26〜12/27）

下北沢発、アクアライン経由で木更津・マザー牧場を巡る家族旅行の旅程ページ `index.html`（モバイル前提の1枚もの）。

- **移動**：ニッポンレンタカー下北沢駅前営業所 12/26 8:00 出発 〜 12/27 20:00 返却。往路はアクアライン経由で木更津金田ICへ
- **1日目**：三井アウトレットパーク 木更津（ショップ10:00〜）→ マザー牧場の午後イベント（こぶたのレース／シープショー／アヒルの大行進）→ グランピングチェックイン → デッキBBQ＆焚き火
- **宿泊**：マザー牧場 グランピング THE FARM「ドームテントスカイプレミアム」（チェックイン14:00以降／チェックアウト10:00）
- **2日目**：モーニングボックスでピクニック朝食と朝体験 → 10:00チェックアウト → 午前〜昼のイベント（ひつじの大行進 12:30〜）＆牧場グルメ → 15:00出発で帰路
- **注意**：マザー牧場の12月土日祝の開園は 9:30〜16:00。帰路はアクアライン上り渋滞の前に早め出発が前提。時間はすべて目安（ざっくり旅程）
- **未確定**：寄り道候補（海ほたるPAなど）は検討中。ページ内の提案タグに記載

## ページの機能（前作・九州旅行ページから引き継ぎ）

- **いま どこ？（リアルタイム表示）**：現在の予定・次の予定・カウントダウンを上部カードに表示（毎分更新）
  - スケジュール内に赤い「いま◯◯:◯◯」ライン、済み予定は薄く✓、現在＝オレンジ／次＝青でハイライト
  - 「いまの ばしょへ」ボタンと起動時の自動スクロール、旅の進みぐあいバー（🚗）
  - 動作確認用に `?t=2026-12-26T13:20` で任意時刻をシミュレート可能
- **案内役「たびクマ」**：次の予定を、予定ごとのひとこと付きで教えてくれる吹き出し
- **日程カード**：日付ジャンプナビ、カードの折りたたみ（全部開く／閉じる）、各日の「完了」トグル、宿泊チップ＋Googleマップ／天気リンク
- **旅のしおり要素**：メンバー紹介、持ち物チェックリスト（冬・グランピング向け4カテゴリ・進捗表示）、旅日記（日ごとに一行）
- **こども向け**：スタンプラリー（8個・タップで収集）、こどもモード（文字を大きく）
  - チェック／日記／スタンプは localStorage に保存（保存キーは `kisarazu_` 接頭辞で前作と分離）
